# UI/UX Design – Project 2: The Blueprint

## DecodeLabs Industrial Training – Batch 2026

This repository contains my UI/UX Design Project 2 – The Blueprint (Wireframing).

### Project Scenario

An e-commerce brand is losing customers during the checkout process. The layout is cluttered, and users are confused. They need a clean and logical structure for their Landing Page.

### Project Objectives

- Design the skeleton of the application
- Focus on user flow and information hierarchy
- Create low-fidelity wireframes for a homepage
- Add clear Call-to-Action (CTA) buttons
- Create a clean and logical structure

### Tools

- Figma
- Pen & Paper

### Design Guidelines

- Black, White, and Grey only
- No images
- No colors
- Focus on structure and usability
